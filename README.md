# Merigi Medical Centre - Rays of Hope 🏥

Merigi Medical Centre is a comprehensive healthcare facility located in Bomet, Kenya. This website is designed to provide the community with 24/7 access to medical information, service inquiries, and health resources.

![Website Preview](public/images/building-exterior.jpg)

## 🌟 Key Features

* **24/7 Service Information**: Detailed sections for Maternity, Inpatient, and Outpatient care.
* **Diagnostic Imaging Hub**: Interactive modal pop-ups showcasing Ultrasound and X-Ray capabilities.
* **Mobile-First Design**: Fully responsive navigation and layouts optimized for smartphones.
* **Interactive Contact Form**: Real-time validation and inquiry submission for patients.
* **SEO-Optimized Health Tips**: A "Community Health Tips" section to improve local search visibility.
* **Automated Footer**: JavaScript-driven copyright year updates.

## 🛠️ Technology Stack

* **HTML5**: Semantic structure for better accessibility and SEO.
* **CSS3**: Custom properties (variables), Flexbox, and Grid for modern layouts.
* **JavaScript (ES6+)**: Handles mobile navigation, service modals, and scroll animations.
* **Google Maps API**: Integrated location services for patient navigation.
